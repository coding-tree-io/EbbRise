# Getting help

- **A question or an idea:** start a [discussion](https://github.com/coding-tree-io/EbbRise/discussions).
- **A bug:** open an [issue](https://github.com/coding-tree-io/EbbRise/issues/new/choose) with the bug form. Include the version (`ebbrise version`), your Windows version, and the log file. `ebbrise logs` prints where it is (`%APPDATA%\EbbRise\logs\main.log`).
- **A security problem:** report it privately, as described in [SECURITY.md](SECURITY.md).

EbbRise has a single maintainer, so answers are not instant.

The [README](README.md) covers install, settings and the command line. Design notes are in [docs](docs).
